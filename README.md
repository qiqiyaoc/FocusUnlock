# FocusUnlock

移除小米 HyperOS 焦点通知（超级岛）白名单限制。

## 编译方式

### 方式1：GitHub Actions 自动编译（推荐）
1. Fork 本仓库或上传到自己的 GitHub
2. 点击 Actions 标签，等待自动编译完成
3. 下载 Artifacts 中的 APK

### 方式2：本地编译
1. 用 Android Studio 打开本项目
2. Sync Gradle，Build APK

## 使用
1. 安装 APK
2. LSPosed 管理器 → 模块 → 启用 FocusUnlock
3. 作用域只勾选：小米服务框架 (com.xiaomi.xmsf)
4. 重启手机
